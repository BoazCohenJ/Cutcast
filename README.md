# Podcast Autocut

An easy local desktop app for putting podcast camera feeds and sound files into one finished video.

## For everyday use

1. Open the app.
2. Click Add camera and pick a camera video.
3. Click Add sound file and attach one or more sound tracks to that camera.
4. Move the sliders so the clips line up.
5. Pick where to save it and click Make video.

## Make a Windows `.exe`

1. Install dependencies with `npm install`.
2. Run `npm run dist:win`.
3. Your Windows installer and portable `.exe` will appear in the `release` folder.

## Notes

- Built for Windows first.
- Uses local files only.
- The Simple guide button in the app shows the same steps in plain language.
